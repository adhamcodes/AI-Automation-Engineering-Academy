# Module 06.1 — When to Use AI

## Capability
Choose AI only when ambiguity/semantic judgement justifies nondeterminism.

## Core model
Rules, search and parsing are cheaper/more predictable for explicit logic. LLMs help with language, fuzzy classification/extraction/summarization—but need eval and fallbacks.

## Practice
Classify 15 automation steps as deterministic/AI/human.

## Failure / debugging task
Replace an LLM used for simple date/status routing with deterministic logic.

## Evidence to save
Architecture decision matrix.

## Mastery
Every AI call has a reason and fallback.
