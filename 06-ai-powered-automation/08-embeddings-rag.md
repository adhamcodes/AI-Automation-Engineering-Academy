# Module 06.8 — Embeddings & RAG for Automation

## Capability
Retrieve internal knowledge when workflow decisions/responses need external evidence.

## Core model
RAG retrieves relevant source material before generation. It needs permissions, freshness, chunking and retrieval evaluation.

## Practice
Build small knowledge retrieval step.

## Failure / debugging task
Test cross-user data leak and missing-evidence response.

## Evidence to save
Retrieval trace + eval queries.

## Mastery
Workflow cites/uses authorized evidence or escalates.
