# Module 06.7 — Summarization & Transformation

## Capability
Summarize/transform while preserving required facts and constraints.

## Core model
Define audience, information that must survive, unacceptable fabrication and length/format requirements.

## Practice
Create meeting/support summaries with checklist scoring.

## Failure / debugging task
Detect omitted critical action or invented claim.

## Evidence to save
Evaluation rubric + regression set.

## Mastery
Summary is useful and evidence-consistent.
