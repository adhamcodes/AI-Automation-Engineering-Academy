# Module 06.2 — Model API Fundamentals

## Capability
Call LLM APIs with explicit configuration, timeouts and provider abstraction.

## Core model
Model calls are remote probabilistic dependencies with rate/cost/availability limits.

## Practice
Build provider-neutral request wrapper or mockable client.

## Failure / debugging task
Handle timeout/429/provider error/refusal.

## Evidence to save
Testable client with usage logging.

## Mastery
Workflow can fail or switch provider without corrupting state.
