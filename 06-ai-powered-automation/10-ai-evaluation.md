# Module 06.10 — AI Workflow Evaluation

## Capability
Create repeatable test cases for nondeterministic components.

## Core model
Evaluation includes task accuracy, format, safety, escalation and cost/latency; use deterministic checks plus human/model-assisted rubrics cautiously.

## Practice
Build 30–50 case dataset for one AI node.

## Failure / debugging task
Catch improvement on happy paths that worsens critical edge cases.

## Evidence to save
Eval harness/report.

## Mastery
Changes are compared against a baseline.
