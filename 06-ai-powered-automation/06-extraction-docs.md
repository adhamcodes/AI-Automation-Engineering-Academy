# Module 06.6 — Extraction & Document Understanding

## Capability
Extract useful fields from messy text/documents with provenance and validation.

## Core model
LLMs can normalize unstructured language but may invent missing fields; preserve source evidence and mark unknown.

## Practice
Extract records from emails/docs and compare to ground truth.

## Failure / debugging task
Test missing field, contradictory document, malicious instruction text.

## Evidence to save
Extraction pipeline with evidence links.

## Mastery
Unknown stays unknown.
