# Module 06.3 — Prompt/System Instructions for Automation

## Capability
Define narrow tasks, context and output expectations.

## Core model
Prompts are behavior hints/contracts, not permission/security systems. Keep input data delimited and task narrow.

## Practice
Write classification/extraction prompts with edge cases.

## Failure / debugging task
Test prompt injection and ambiguous instruction conflict.

## Evidence to save
Versioned prompt + eval cases.

## Mastery
You can state what cannot be enforced by prompt.
