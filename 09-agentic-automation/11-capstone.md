# Module 09.11 — Agentic Automation Capstone

## Capability
Build a bounded agent inside a reliable business automation.

## Core model
The capstone combines tools, state, approval, deterministic guardrails, recovery, evaluation and observability.

## Practice
Use unfamiliar scenario with 2–4 tools.

## Failure / transfer task
Inject malicious content, tool outage, repeated action and low-confidence decision.

## Evidence to save
Case study + eval results + runbook.

## Mastery
System fails safely and human/operator can understand why.
