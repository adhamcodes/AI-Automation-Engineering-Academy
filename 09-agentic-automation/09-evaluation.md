# Module 09.9 — Agent Evaluation

## Capability
Evaluate tool choice, arguments, trajectory, recovery and final outcome.

## Core model
A good final message can hide unsafe tool use; trajectory tests inspect intermediate behavior.

## Practice
Create expected/forbidden tool-use cases.

## Failure / transfer task
Catch correct output produced after unauthorized lookup.

## Evidence to save
Eval dataset + scorers/rubric.

## Mastery
Agent changes are regression-tested.
