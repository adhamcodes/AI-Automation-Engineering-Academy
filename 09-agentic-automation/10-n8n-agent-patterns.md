# Module 09.10 — n8n Agent Patterns

## Capability
Implement agentic pieces in n8n without hiding deterministic orchestration.

## Core model
Use AI Agent/tools/memory where justified; keep validation/state/error branches visible and testable.

## Practice
Build agent subworkflow wrapped by deterministic parent.

## Failure / transfer task
Diagnose agent node doing too many unrelated responsibilities.

## Evidence to save
Modular workflow export + diagram.

## Mastery
Another engineer can inspect control boundaries.
