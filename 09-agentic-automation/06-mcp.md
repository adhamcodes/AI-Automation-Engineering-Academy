# Module 09.6 — MCP for Automation

## Capability
Understand interoperable tool/resource access and its trust boundaries.

## Core model
MCP standardizes connections but does not replace authentication, authorization, data policy or workflow design.

## Practice
Connect to a local/practice MCP server or inspect protocol examples.

## Failure / transfer task
Spot overprivileged server/tool.

## Evidence to save
Trust-boundary diagram.

## Mastery
Protocol convenience does not weaken permissions.
