# Module 09.5 — Memory

## Capability
Use memory only with purpose, provenance and correction/delete rules.

## Core model
Distinguish session context, durable user facts and retrieved history. More stored text can make behavior worse.

## Practice
Design memory schema with source/time/confidence.

## Failure / transfer task
Correct stale fact and prove future run uses update.

## Evidence to save
Memory governance note.

## Mastery
You can explain why each memory exists.
