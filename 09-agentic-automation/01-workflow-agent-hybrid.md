# Module 09.1 — Workflow vs Agent vs Hybrid

## Capability
Choose bounded agency only for variable decision paths.

## Core model
Deterministic orchestration remains the default for known business rules. Agents are useful when selecting tools/steps from ambiguous inputs but increase testing and security burden.

## Practice
Classify ten tasks and redesign an over-agentized example.

## Failure / transfer task
Show how a fixed workflow can wrap one agentic decision safely.

## Evidence to save
Architecture decision matrix.

## Mastery
You can state why agency is worth its failure surface.
