# Module 09.2 — Tool Contracts

## Capability
Expose narrow validated tools to models.

## Core model
Tools should have typed inputs, least privilege, explicit side effects and structured errors.

## Practice
Design tools for lookup/draft/update with different permissions.

## Failure / transfer task
Reject arbitrary SQL/shell/full-account access.

## Evidence to save
Tool schemas + validation tests.

## Mastery
Model cannot create a capability it was not granted.
