# Module 12.4 — Vertical Automation Systems

## Capability
Package end-to-end workflow for a narrow recurring operational problem.

## Core model
Vertical system combines domain process, integrations, configuration and operations; domain assumptions must be explicit.

## Practice
Design e.g. lead qualification/onboarding/reporting vertical system.

## Failure / transfer task
Identify customer variation that breaks supposed standardization.

## Evidence to save
Config schema + architecture.

## Mastery
Core remains reusable across target users.
