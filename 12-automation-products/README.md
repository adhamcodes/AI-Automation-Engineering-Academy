# Phase 12 — Automation Products

**Typical effort:** Open-ended advanced track

## Purpose
Convert repeated validated automation work into reusable systems/products without prematurely becoming a SaaS founder.

## Modules
1. Productization Signals
2. Templates vs Reusable Systems
3. Custom Connectors / Nodes
4. Vertical Automation Systems
5. Platform & Licensing Alternatives
6. Multi-Tenant Awareness
7. Product Operations & Support
8. Advanced Product Capstone

## Gate
Pass **Reusable Product/System Builder** when the same core works safely for multiple configurations and the operating/licensing burden is understood.
