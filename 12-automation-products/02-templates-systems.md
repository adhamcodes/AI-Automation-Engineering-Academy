# Module 12.2 — Templates vs Reusable Systems

## Capability
Choose artifact level appropriate to variability.

## Core model
Template copies configuration; reusable system abstracts stable logic and exposes controlled configuration. Too much abstraction creates platform prematurely.

## Practice
Extract reusable component from two simulated workflows.

## Failure / transfer task
Spot template leaking credentials/client-specific IDs.

## Evidence to save
Parameterization/design doc.

## Mastery
Reuse does not sacrifice clarity or isolation.
