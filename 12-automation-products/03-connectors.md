# Module 12.3 — Custom Connectors / Nodes

## Capability
Build reusable integration components when generic HTTP/custom code becomes repetitive.

## Core model
Connector encapsulates authentication, API operations, pagination/error semantics and typed inputs.

## Practice
Design custom n8n node or Python package wrapper for practice API.

## Failure / transfer task
Handle API version/rate/error changes.

## Evidence to save
Connector + tests/docs.

## Mastery
Integration behavior is reusable and versioned.
