# Phase 5 — JavaScript for Automation Engineers

**Typical effort:** ~1–2 weeks

## Purpose
Learn only the JavaScript needed for workflow data, async API calls and custom n8n logic.

## Modules
1. JavaScript Values & Objects
2. Arrays: map/filter/reduce
3. Functions & Modules
4. Promises & async/await
5. HTTP with fetch
6. Errors & Validation
7. n8n Code Node Patterns
8. JavaScript Automation Assessment

## Gate
Pass **Custom Logic Ready**; no frontend framework is required.
