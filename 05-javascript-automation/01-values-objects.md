# Module 05.1 — JavaScript Values & Objects

## Capability
Read/write JSON-like workflow data confidently.

## Core model
Automation JS mostly manipulates primitives, arrays and objects. Understand mutability/reference behavior enough to avoid surprising edits.

## Practice
Transform nested API objects without losing fields.

## Failure / debugging task
Fix undefined/property/path and accidental mutation bugs.

## Evidence to save
Small data-normalizer functions.

## Mastery
You can inspect unknown object shape and transform safely.
