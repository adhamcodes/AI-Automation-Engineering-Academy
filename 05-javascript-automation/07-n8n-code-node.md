# Module 05.7 — n8n Code Node Patterns

## Capability
Use custom JS only where node/expression composition becomes less clear.

## Core model
Code nodes are escape hatches for complex transformations, not excuses to hide entire workflows in opaque scripts.

## Practice
Implement one complex transformation and compare with native nodes.

## Failure / debugging task
Refactor huge Code node into modules/subworkflow/API service.

## Evidence to save
Documented Code node with tests/sample input-output.

## Mastery
You can explain why code belongs there.
