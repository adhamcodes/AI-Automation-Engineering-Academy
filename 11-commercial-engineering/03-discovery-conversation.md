# Module 11.3 — Discovery Conversations

## Capability
Ask process questions without turning call into tool pitch.

## Core model
Understand current steps, actors, systems, volumes, exceptions, failure cost, data/privacy and desired outcome.

## Practice
Role-play discovery and write notes/process map.

## Failure / transfer task
Catch vague stakeholder assumption and conflicting goals.

## Evidence to save
Discovery template.

## Mastery
You can restate process accurately before proposing solution.
