# Module 11.13 — Commercial Delivery Gate

## Capability
Demonstrate readiness to scope and deliver paid work responsibly.

## Core model
This gate tests discovery, scope, demo, pricing assumptions, security/ownership, documentation and support—not sales charisma.

## Practice
Mock client brief from first message through proposal/handover plan.

## Failure / transfer task
Stakeholder changes requirement and asks for risky access.

## Evidence to save
Complete commercial packet.

## Mastery
Pass means ready to pursue work, not guaranteed customers.
