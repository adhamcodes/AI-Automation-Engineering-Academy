# Module 11.8 — Client Security & Data Responsibility

## Capability
Set permissions/data handling/incident obligations proportional to access.

## Core model
Least privilege, secret handling, data retention, subprocessors, backups and breach response become commercial responsibilities.

## Practice
Create client access/credential checklist.

## Failure / transfer task
Reject request to share one admin password across systems.

## Evidence to save
Security handover checklist.

## Mastery
You know what data/access you hold.
