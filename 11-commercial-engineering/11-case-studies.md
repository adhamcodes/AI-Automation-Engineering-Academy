# Module 11.11 — Case Studies & Portfolio

## Capability
Turn builds into credible evidence.

## Core model
Case study: problem, current process, architecture, why choices, demo, failures handled, outcome/estimated impact, limitations. Avoid fake customer claims.

## Practice
Convert one simulated project into transparent “demonstration case.”

## Failure / transfer task
Remove fabricated ROI/testimonial.

## Evidence to save
Published/local case study.

## Mastery
Claims are true and inspectable.
