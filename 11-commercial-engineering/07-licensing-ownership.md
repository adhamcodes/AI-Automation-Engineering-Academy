# Module 11.7 — Platform Licensing & Ownership

## Capability
Choose hosting/ownership model that complies with current platform terms and client needs.

## Core model
Client-owned instances, your managed infrastructure and embedded products can have different licensing/security/support implications. Re-check current terms before selling.

## Practice
Compare client-owned n8n vs managed/embedded scenario using current license guidance.

## Failure / transfer task
Flag architecture that hosts client workflows/credentials without appropriate license review.

## Evidence to save
Ownership/licensing decision checklist.

## Mastery
Contract/architecture matches actual responsibility.
