# Phase 3 Mastery Assessment — Code-Assisted Automation

**Mode:** no AI-generated implementation for the core build. Official Python/library docs allowed.

Build from a specification:
- CLI ingests files or parameters;
- Python calls an unfamiliar practice API with timeout/error policy;
- transforms/validates results;
- exposes one operation through FastAPI;
- logs run evidence;
- has tests for happy/failure cases;
- n8n calls the service and handles one injected failure.

## Pass
You must demonstrate code ownership: explain modules/functions, test strategy, retry boundary, and why service/workflow responsibilities are split as they are.
