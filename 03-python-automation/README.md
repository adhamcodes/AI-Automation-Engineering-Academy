# Phase 3 — Python Automation

**Expected effort:** ~3–4 weeks.

## Purpose
Move beyond what visual nodes can express cleanly. Python becomes the custom-logic layer for HTTP clients, file/data pipelines, command-line tools, small services, scheduling, logging, retries, and tests. n8n remains an orchestrator when it is the better orchestration tool.

## Modules
1. HTTP clients with timeouts and explicit errors
2. JSON/CSV/filesystem pipelines
3. configuration and environment variables
4. command-line automation tools
5. logging and run evidence
6. retries and resilient client functions
7. data transformation and validation
8. FastAPI service fundamentals
9. background-work boundaries
10. testing automation code
11. n8n ↔ Python integration project
12. mastery assessment

## Gate
Pass to become a **Code-Assisted Automation Builder**. Commercial readiness still depends on persistent-state/reliability work in Phase 4.
