# Phase 0 Gate — Automation Thinking

**Assistance:** closed-assistance for the first attempt.

Scenario:

> A five-person recruiting agency receives candidate CVs by email, manually saves attachments, updates a spreadsheet, messages recruiters, and often loses track of who reviewed what.

Produce:
1. a current-state process map
2. discovery questions
3. automation candidates
4. steps that should remain human-controlled initially
5. major failure/security risks
6. a minimal future-state workflow specification

Pass when another engineer could understand the proposed process without asking you to explain basic missing steps.
