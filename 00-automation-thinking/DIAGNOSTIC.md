# Automation Entry Diagnostic

No prior automation-platform experience is required.

## A. Process reasoning
Given a manual process, identify trigger, inputs, decisions, outputs, failure points, and human handoffs.

## B. Technical baseline
Explain what you currently know about:
- HTTP
- JSON
- API
- webhook
- database
- Git
- Python

"I don't know" is a valid diagnostic answer.

## C. Build instinct
You receive: "Whenever a spreadsheet row is added, send its contents to another service."
Write the questions you would ask before building anything.

## D. Commercial comfort
Rate 0–3:
- talking to a stranger about their process
- writing a short proposal
- demonstrating your work publicly
- asking for payment
- supporting something after delivery

These answers do not block technical progression. They determine which commercial exercises need more gradual exposure.
