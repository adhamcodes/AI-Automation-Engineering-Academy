# Core Completion Standard

You have completed the core when you can independently:

- turn a messy manual process into a precise workflow specification;
- integrate unfamiliar APIs from documentation, including auth/pagination/rate limits/errors;
- build modular n8n workflows and custom Python/JavaScript logic;
- maintain persistent state safely with SQL and idempotent designs;
- decide when deterministic logic, an LLM, an agent, or a human should act;
- automate browser/document work only when APIs are insufficient and the approach is lawful/reliable;
- deploy and operate workflows with Docker, logging, monitoring, backups, secrets, and recovery;
- scope, demonstrate, document, hand over, and support a client-grade system;
- show portfolio evidence based on failure handling and business outcomes, not screenshots alone.
