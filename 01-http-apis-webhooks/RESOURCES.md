# Phase 1 Resource Map

The academy notes define the learning target. External resources deepen and verify it.

## Primary references
- **MDN — HTTP overview:** https://developer.mozilla.org/en-US/docs/Web/HTTP/Guides/Overview
  - Use for client/server, request/response flow, HTTP-message mental model.
- **MDN — HTTP methods:** https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Methods
  - Use for method semantics and the ideas of safety/idempotency.
- **MDN — HTTP status codes:** https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Status
  - Reference when interpreting response classes/codes.
- **Postman Quick Start:** https://learning.postman.com/docs/getting-started/quick-start
  - Use for first controlled requests and basic tests.
- **Postman request basics:** https://learning.postman.com/docs/use/send-requests/create-requests/request-basics
  - Reference for URL, method, auth, parameters, headers, body.

## Practice / bridge to Phase 2
- **n8n Academy N8N101:** https://learn.n8n.io/courses/course-v1%3An8n%2BN8N101%2B2026H2/about
  - Optional early workflow orientation.
- **n8n Academy N8N102:** https://learn.n8n.io/courses/course-v1%3An8n%2BN8N102%2B2026H2/about
  - Strong bridge after Phase 1: HTTP Request node, auth, pagination, webhooks, control flow, credentials.

## Resource rules
- Do not complete resources for badges. Use them to achieve the module capability.
- If an interface screenshot changes, preserve the concept and consult current official docs.
- Never paste real secrets into public practice artifacts.
## Maintenance metadata
- MDN HTTP guides — **REFERENCE / DURABLE**, review URL yearly.
- Postman docs — **PRACTICE + REFERENCE / REVIEW YEARLY**; focus on raw request construction, skip AI/Flows features in this phase.
- n8n Academy — **OPTIONAL BRIDGE / REVIEW YEARLY**; use only after HTTP concepts are understood.
