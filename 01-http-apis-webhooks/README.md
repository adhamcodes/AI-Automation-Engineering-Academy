# Phase 1 — HTTP, APIs & Webhooks

**Expected effort:** roughly 2 weeks at 2–3 focused hours/day. Move by mastery, not calendar.

## Phase capability
By the end of this phase, you should be able to take unfamiliar API documentation, determine how to authenticate, send and inspect requests, handle pagination/rate limits/failures, and design either a webhook- or polling-based integration without blindly following a tutorial.

## Learning order
1. Client/server and HTTP mental model
2. Methods, headers, and status codes
3. JSON and request/response bodies
4. REST conventions and reading API docs
5. API keys, bearer tokens, and OAuth concepts
6. Pagination
7. Rate limits
8. Retries and backoff
9. Webhooks vs polling
10. Idempotency
11. Error handling
12. API exploration with Postman
13. Integration challenge + mastery assessment

## Rule for this phase
Do not memorize APIs. Learn to **read contracts**. A new service should feel unfamiliar, not mysterious.

## Phase gate
You pass when you can integrate a small unfamiliar API from its documentation, explain the request/response flow, handle common failure conditions, and justify your reliability choices.
