# Parallel Study and Prerequisite Gates

This academy is meant to run beside normal software-engineering study, not replace it.

## Git/GitHub

Complete the core of `adhamcodes/git-github-course` early. By the time you reach serious Python services, production deployment, and collaboration work here, Git status/diff/commits/branches/remotes/recovery should feel normal.

## Before Phase 3 — Python Automation

You should already be able to write and debug small Python programs using functions, modules, files, exceptions, virtual environments, and basic tests.

If not, pause this phase and repair the software-engineering prerequisite instead of copying Python you cannot explain.

## Before Phase 10 — Production Reliability

You should already be comfortable with:

- Git branches and pull requests,
- HTTP request/response behavior,
- automated tests,
- environment/configuration separation,
- command-line debugging.

## AI/ML overlap

Automation Phase 6 does not require completing the full AI/ML academy. It does require evaluation discipline: frozen cases, failure analysis, structured outputs, safety boundaries, and knowing when AI should not be used.

The rule is simple: **when a prerequisite is missing, repair it instead of hiding it with a tutorial or generated solution.**
