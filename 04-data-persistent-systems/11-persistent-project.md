# Module 04.11 — Persistent Automation Project

## Capability
Build a restart-safe database-backed automation.

## Core model
Combine API/workflow/code with durable state, idempotent events, transactions and operational status.

## Practice
Create e.g. lead/onboarding/report pipeline with database state.

## Failure / debugging task
Inject duplicate webhook, mid-run crash, DB transient failure and retry.

## Evidence to save
Repo/workflow export, schema, tests, runbook.

## Mastery
System resumes correctly and produces no duplicate external action.
