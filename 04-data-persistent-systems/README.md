# Phase 4 — Data & Persistent Systems

**Typical effort:** ~2–3 weeks

## Purpose
Move from one-shot workflows to restart-safe systems with SQL, explicit state, idempotency and concurrency awareness.

## Modules
1. Relational Data Modeling
2. SQL CRUD Safely
3. Joins & Aggregation
4. Transactions
5. Indexes & Query Performance
6. PostgreSQL Operations Basics
7. Workflow State Machines
8. Idempotency & Deduplication
9. Queues & Workers
10. Concurrency & Race Conditions
11. Persistent Automation Project
12. Reliable Integration Builder Assessment

## Gate
Pass **Reliable Integration Builder**: repeated events, retries and restarts do not corrupt business state.
