# Module 04.5 — Indexes & Query Performance

## Capability
Use indexes based on real query/filter/join patterns.

## Core model
Indexes trade write/storage cost for faster lookup/order; a missing or useless index is diagnosed from workload, not superstition.

## Practice
Compare query plans/timing on indexed vs unindexed lookup.

## Failure / debugging task
Find slow query caused by unselective or mismatched index.

## Evidence to save
Short performance note.

## Mastery
You can explain which query an index supports.
