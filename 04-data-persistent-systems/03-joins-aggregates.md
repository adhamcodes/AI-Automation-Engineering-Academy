# Module 04.3 — Joins & Aggregation

## Capability
Combine relational data and compute operational summaries.

## Core model
Joins combine rows through relationships; aggregation changes row grain. Wrong join cardinality can silently duplicate results.

## Practice
Write inner/left joins, group/aggregate and window-aware summaries.

## Failure / debugging task
Diagnose inflated revenue/lead counts from many-to-many join.

## Evidence to save
Reporting queries with expected-row tests.

## Mastery
You can state input/output grain of a query.
