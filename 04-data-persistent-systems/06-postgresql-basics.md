# Module 04.6 — PostgreSQL Operations Basics

## Capability
Use a real relational database for automation state without becoming a DBA.

## Core model
Know database/schema/user/role/connection concepts, backups and migrations enough to run application state safely.

## Practice
Create database/user/schema, connect via client, apply migration script.

## Failure / debugging task
Recover from wrong connection string/permission/migration order.

## Evidence to save
Documented local Postgres setup.

## Mastery
Environment can be rebuilt without GUI-only steps.
