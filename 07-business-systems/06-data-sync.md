# Module 07.6 — Cross-System Data Synchronization

## Capability
Keep systems aligned without creating loops/duplicate updates.

## Core model
Define source of truth, field ownership, change detection, conflict policy and idempotent upsert.

## Practice
Sync CRM↔internal DB or two practice services.

## Failure / debugging task
Create ping-pong update loop then prevent it.

## Evidence to save
Sync contract + reconciliation report.

## Mastery
You can explain authoritative field ownership.
