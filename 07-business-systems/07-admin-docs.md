# Module 07.7 — Admin & Document Workflows

## Capability
Automate repetitive document/email/file operations with structured checkpoints.

## Core model
Files have identity/version/retention and may contain sensitive data; transformations need provenance.

## Practice
Intake attachments, classify/store/extract/notify.

## Failure / debugging task
Handle duplicate file, corrupted PDF, sensitive document.

## Evidence to save
Document pipeline + manifest.

## Mastery
Every output can be traced to source input.
