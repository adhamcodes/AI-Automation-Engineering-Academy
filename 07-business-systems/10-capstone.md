# Module 07.10 — Business Systems Capstone

## Capability
Translate an ambiguous business complaint into a client-grade system.

## Core model
The capstone integrates discovery, architecture, state, APIs/code/AI as justified, testing and handover.

## Practice
Receive messy scenario and ask clarifying questions before building.

## Failure / debugging task
Evaluator changes one requirement and injects service failure.

## Evidence to save
Case study: before process, architecture, demo, failure tests, outcome/limitations.

## Mastery
Pass earns **Client-Grade Automation Builder**.
