# Module 07.8 — Requirements Discovery

## Capability
Turn “please automate this” into observed current process, pain and constraints.

## Core model
Ask who/what/when/volume/exceptions/systems/data/permissions/failure cost; separate desired outcome from requested tool.

## Practice
Conduct mock discovery from a messy brief.

## Failure / debugging task
Find hidden manual exception that breaks naive workflow.

## Evidence to save
Current-state/future-state process map.

## Mastery
Specification contains normal and abnormal paths.
