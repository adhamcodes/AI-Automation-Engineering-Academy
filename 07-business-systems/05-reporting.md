# Module 07.5 — Reporting & Scheduled Operations

## Capability
Build reliable scheduled data collection/transformation/report delivery.

## Core model
Reports require data freshness, completeness checks, reproducible calculations and delivery status.

## Practice
Create weekly report from two APIs/DB sources.

## Failure / debugging task
Handle partial source outage and stale data.

## Evidence to save
Report pipeline + data-quality checks.

## Mastery
Report labels incomplete/stale data instead of fabricating completeness.
