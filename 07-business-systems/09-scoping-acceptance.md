# Module 07.9 — Scoping & Acceptance Criteria

## Capability
Define what is included, excluded and how success is verified.

## Core model
Scope controls risk: systems/accounts, volumes, features, data migration, deployment ownership, support and acceptance tests.

## Practice
Write scope for a 1–2 week automation build.

## Failure / debugging task
Detect vague “AI agent handles everything” commitment.

## Evidence to save
Scope + acceptance test list.

## Mastery
A third party can decide whether delivery passes.
