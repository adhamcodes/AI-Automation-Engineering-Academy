# Phase 2 — Workflow Engineering with n8n

**Expected effort:** roughly 2–3 weeks at 2–3 focused hours/day.

## Purpose
Use n8n as an orchestration environment while preserving the engineering concepts learned in Phase 1. The goal is not to memorize nodes. It is to design workflows whose data flow, branching, failure behavior, credentials, and maintenance strategy you can explain.

## Modules
1. workflow execution and data items
2. expressions and data mapping
3. branching and decision logic
4. loops, batching, and waits
5. triggers, schedules, and webhooks
6. credentials and configuration
7. sub-workflows and modularity
8. error workflows, retries, and recovery
9. debugging execution history
10. naming, documentation, and basic monitoring
11. integration project
12. mastery assessment

## Commercial Gate 1
Pass this phase and its project to earn **Useful Workflow Builder** status. This means you can build useful small automations. It does not yet mean you are ready to own complex client production systems.
