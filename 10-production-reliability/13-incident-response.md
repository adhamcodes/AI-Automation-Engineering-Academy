# Module 10.13 — Incident Response

## Capability
Respond to failed automations systematically.

## Core model
Detect → contain → restore → communicate → learn. Preserve evidence and prevent repeated harm before optimizing root cause.

## Practice
Run tabletop incident: duplicate customer actions/API credential leak/outage.

## Failure / transfer task
Write timeline and corrective actions.

## Evidence to save
Incident report template.

## Mastery
You distinguish immediate mitigation from long-term fix.
