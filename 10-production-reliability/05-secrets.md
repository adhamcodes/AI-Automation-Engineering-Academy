# Module 10.5 — Secrets & Configuration

## Capability
Keep credentials out of code/workflow exports/logs.

## Core model
Use environment/credential stores, least privilege, rotation and separation between environments.

## Practice
Audit repo/workflow for secrets.

## Failure / transfer task
Rotate leaked practice credential and clean history if needed.

## Evidence to save
Secrets checklist.

## Mastery
No secret appears in Git or user-visible logs.
