# Module 10.9 — Backups & Disaster Recovery

## Capability
Recover systems and state, not merely copy files.

## Core model
Define RPO/RTO, backup database/config/credentials/encryption keys/workflow definitions and test restore.

## Practice
Create and restore practice backup.

## Failure / transfer task
Discover backup without encryption key/schema version is useless.

## Evidence to save
DR checklist + restore evidence.

## Mastery
Restore test proves backup works.
