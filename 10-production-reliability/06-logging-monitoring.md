# Module 10.6 — Logging, Monitoring & Alerts

## Capability
Know whether automations are running correctly.

## Core model
Track run IDs, inputs identifiers (not sensitive payloads), status, latency, retries, external calls and business outcome metrics. Alert on actionable conditions.

## Practice
Create dashboard/report/alerts for failed and stuck runs.

## Failure / transfer task
Find silent failure where workflow executed but business outcome missing.

## Evidence to save
Operational dashboard/run log.

## Mastery
You can answer what failed, when, and impact.
