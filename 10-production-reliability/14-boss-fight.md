# Module 10.14 — Production Reliability Boss Fight

## Capability
Operate a deliberately failing automation stack.

## Core model
The gate combines deployment, observability, security, backups and recovery.

## Practice
Deploy stack then handle injected service outage, duplicate event, secret exposure and corrupt state.

## Failure / transfer task
Evaluator restarts components and sends malicious webhook.

## Evidence to save
Runbook, tests, restored service and postmortem.

## Mastery
Pass earns **Automation Engineer**.
