# Module 10.12 — Testing & Release Discipline

## Capability
Ship workflow/code changes with regression evidence and rollback.

## Core model
Version exports/code/config; test representative and failure cases; deploy progressively where possible.

## Practice
Create release checklist and regression pack.

## Failure / transfer task
Break downstream field contract and catch before production.

## Evidence to save
Release artifact + changelog.

## Mastery
You can roll back safely.
