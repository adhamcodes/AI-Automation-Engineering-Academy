# Module 10.10 — API & Webhook Security

## Capability
Authenticate requests, authorize actions and limit abuse.

## Core model
Use signatures/tokens/OAuth appropriately, validate payloads, rate/resource limits and avoid trusting user-controlled URLs/data.

## Practice
Secure webhook with signature/secret and replay protection.

## Failure / transfer task
Inject spoofed/replayed webhook and SSRF-like URL field.

## Evidence to save
Security tests.

## Mastery
Unauthorized input cannot trigger privileged action.
