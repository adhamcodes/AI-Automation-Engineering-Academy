# Module 10.3 — Linux/VPS Fundamentals

## Capability
Operate a small server safely enough for automation workloads.

## Core model
Understand processes, ports, filesystem permissions, service logs, updates, users/SSH and resource limits.

## Practice
Deploy practice stack to local VM/VPS if available.

## Failure / transfer task
Diagnose disk full/port conflict/process crash.

## Evidence to save
Server runbook.

## Mastery
You can recover without reinstalling everything.
