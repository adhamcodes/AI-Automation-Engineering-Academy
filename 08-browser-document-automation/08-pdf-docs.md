# Module 08.8 — PDF & Document Pipelines

## Capability
Extract/transform/store documents with provenance and confidence limits.

## Core model
PDF is presentation format; text/tables/scans vary. Preserve source file identity and route low-confidence extraction to review.

## Practice
Process text PDF + table-like doc; record source/page references.

## Failure / transfer task
Handle encrypted/scanned/corrupt file.

## Evidence to save
Document manifest + extraction output.

## Mastery
Unknown/failed extraction is explicit.
