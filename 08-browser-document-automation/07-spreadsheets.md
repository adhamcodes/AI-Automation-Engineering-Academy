# Module 08.7 — Spreadsheet Automation

## Capability
Treat spreadsheets as structured-but-fragile business interfaces.

## Core model
Define headers/types/IDs, avoid positional assumptions, preserve formulas/format only where necessary, validate rows and handle concurrent edits.

## Practice
Read/write/merge a practice spreadsheet pipeline.

## Failure / transfer task
Detect duplicate IDs, shifted columns and malformed date/currency.

## Evidence to save
Validation report + idempotent update strategy.

## Mastery
Repeated run does not duplicate rows.
