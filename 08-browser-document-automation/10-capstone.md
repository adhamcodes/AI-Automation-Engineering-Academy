# Module 08.10 — Browser & Document Capstone

## Capability
Combine browser/file/document automation with API-first and reliability discipline.

## Core model
Use UI automation only at the unavoidable boundary; keep state/validation/recovery outside it.

## Practice
Build an end-to-end practice process with one UI-only step and file artifact.

## Failure / transfer task
Change selector/timing, expire session, corrupt file.

## Evidence to save
Repo/workflow + decision record + tests/runbook.

## Mastery
System degrades safely and tells operator what failed.
