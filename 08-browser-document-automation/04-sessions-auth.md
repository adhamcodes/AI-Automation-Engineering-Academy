# Module 08.4 — Sessions, Authentication & Secrets

## Capability
Handle authenticated browser workflows without leaking credentials.

## Core model
Prefer supported OAuth/API auth. Browser sessions/cookies are sensitive; store secrets outside code and respect MFA/security controls.

## Practice
Use a practice login/session or stored state safely.

## Failure / transfer task
Recover from expired session without bypassing security.

## Evidence to save
Credential/session handling note.

## Mastery
No credentials/cookies committed to Git.
