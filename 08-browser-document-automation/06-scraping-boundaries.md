# Module 08.6 — Scraping Boundaries & Responsible Collection

## Capability
Collect web data within technical, legal, contractual and ethical constraints.

## Core model
Respect terms, robots/rate limits where applicable, privacy/copyright/data-use constraints and site load. Prefer licensed/official sources.

## Practice
Design a low-rate practice collector with caching.

## Failure / transfer task
Reject task requiring bypass of access controls/anti-bot protections.

## Evidence to save
Collection policy + provenance fields.

## Mastery
You can explain why a source/use is permissible.
