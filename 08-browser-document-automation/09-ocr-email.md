# Module 08.9 — OCR & Email Attachment Awareness

## Capability
Understand when OCR/email processing introduces uncertainty/security issues.

## Core model
OCR is probabilistic; attachments can be malicious/sensitive. Validate file types/size, sandbox where needed, retain provenance and human review for critical fields.

## Practice
Design invoice/email intake with confidence threshold.

## Failure / transfer task
Inject unreadable scan and spoofed attachment type.

## Evidence to save
Threat/failure checklist.

## Mastery
Automation does not silently trust OCR output.
