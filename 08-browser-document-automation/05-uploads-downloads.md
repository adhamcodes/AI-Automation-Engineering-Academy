# Module 08.5 — Uploads, Downloads & Files

## Capability
Move files through web workflows with verification.

## Core model
File operations need expected type/name/size/checksum and safe temporary paths.

## Practice
Automate upload/download against practice site and verify artifact.

## Failure / transfer task
Handle wrong file, duplicate download and partial failure.

## Evidence to save
File manifest + cleanup policy.

## Mastery
Output is verified, not just “download event happened.”
