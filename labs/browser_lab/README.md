# Browser Automation Lab

Serve `site/index.html` locally and automate it with Playwright or the browser tool taught by the phase.

Required behaviors:

- fill and submit the form,
- assert the success state,
- use stable locators,
- handle a missing required field,
- capture useful failure evidence.

Then change a non-semantic CSS class in the page. A robust automation should keep working if it used labels/roles or stable attributes rather than brittle styling selectors.
