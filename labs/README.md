# Automation Engineering Labs

These labs are the executable layer of the academy.

They exist to give you stable inputs, failure cases, evaluators, and local systems so the curriculum does not depend on random websites or imaginary boss fights.

Rules:

- work on copies in your own implementation repository,
- predict before running,
- do not edit evaluators to make a failure disappear,
- keep real credentials out of labs,
- prefer deterministic logic before AI,
- document the failure and repair, not only the final green result.

See `../LAB_MAP.md` for phase mapping.
